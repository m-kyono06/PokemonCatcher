# PokemonCatcher

日本語版『ポケットモンスター ソウルシルバー』で、今いる場所に出現する未捕獲ポケモンを、Lua対応のAndroid版melonDSの下画面に重ねて表示する試作です。

## 現在できること

- プレイ中のマップIDと図鑑の「捕まえた」情報を毎フレーム読み、現在地の通常出現データと照合します。
- ゲーム内の図鑑に捕獲が反映されると、レポートを書く前でもリストから消えます。マップ移動やセーブステートの読み込み後も、その時点のゲーム内データを読み直します。
- 草むら・洞窟などの陸上、なみのり、釣り（竿ごと）、いわくだきの候補を表示します。陸上の候補が時間帯によって異なる場所では、朝・昼・夜の候補を併記します。
- ゲーム内メモリは読み取り専用で参照します。

## 使い方

1. [Lua対応のAndroid版melonDS（非公式フォーク）](https://github.com/RicksCodes/MelonDS_Android_wLuaScript)を用意します。
2. [`soulsilver_jp_overlay.lua`](./soulsilver_jp_overlay.lua) をダウンロードし、Android端末に保存します。
3. 日本語版ソウルシルバーを起動し、ポーズメニューの **Lua scripts** から保存したファイルを読み込みます。
4. プレイを再開すると、下画面に現在地の未捕獲リストが表示されます。

## 上画面の左右にドット絵を表示

改修版melonDSでは、日本語版『ダイヤモンド』『パール』『プラチナ』『ハートゴールド』『ソウルシルバー』の通常出現ポケモンを、上画面の左右の余白にアイコンで表示できます。作品に合ったLuaを読み込むと、バージョンを自動判別して出現候補を表示します。[ビルドと導入の手順](./sidebar/README.md)に、専用Lua、アイコン画像、melonDS用パッチへの案内があります。

## 対応範囲と検証状況

- 下画面の一覧表示は日本語版ソウルシルバー（ゲームコード `IPGJ`）に対応しています。通常のAndroid版melonDSには、このスクリプトを読み込むためのLua機能がありません。
- 見出し、地名、ポケモン名、出現方法を日本語で表示します。日本語の表示に必要なフォントはLuaファイルに内蔵しています。
- 通常の野生出現が対象です。大量発生やサファリゾーンなどの特殊な出現条件には対応していません。
- 模擬メモリで、捕獲、捕獲前への巻き戻し、マップ移動に伴う表示更新を確認済みです。Android実機での動作は未確認です。

出現データとゲーム内のデータ構造は [pret/pokeheartgold](https://github.com/pret/pokeheartgold)、日本語版のメモリ参照位置は [HGSS RNG Lua Scripts](https://github.com/splaycosy/Pokemon-Gen4-RNG-Lua-Scripts) を参照しています。
